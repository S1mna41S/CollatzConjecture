# Анализ гипотезы Коллатца

Небольшой Python-проект для исследования последовательностей Коллатца: подсчёта числа шагов до первого попадания в цикл **4 → 2 → 1**, поиска максимума и анализа линейного тренда.

График строится **по желанию** и оформлен в тёмной теме.

## Возможности

- Расчёт количества шагов для всех натуральных чисел от `1` до заданного `N`.
- Ускорение вычислений за счёт кеширования уже пройденных последовательностей.
- Расчёт среднего и максимального количества шагов.
- Вывод **всех начальных чисел**, для которых достигается максимальное количество шагов.
- Линейная аппроксимация `y = kx + b` и расчёт коэффициента детерминации `R²`.
- Опциональное построение графика с линией тренда.

## Установка

Требуется Python 3.10+ и библиотеки NumPy и Matplotlib.

```bash
python -m pip install numpy matplotlib
```

> Для расчётов и вывода тренда графическое окно не требуется. Matplotlib используется только при запуске с `--plot`.

## Использование

Запуск со значением по умолчанию (`10 000` чисел):

```bash
python main.py
```

Проверить первый миллион натуральных чисел **без графика**:

```bash
python main.py --count 1000000
```

Построить график для первых `100 000` чисел:

```bash
python main.py --count 100000 --plot
```

| Аргумент | Назначение | По умолчанию |
|---|---|---|
| `--count N` | Проверить числа от `1` до `N` включительно (`N >= 2`) | `10000` |
| `--plot` | Показать график | Выключено |

## Результаты

Программа выводит:

```text
Количество чисел: ...
Среднее количество шагов: ...
Максимальное количество шагов: ...
Числа с максимальным количеством шагов: ...
Коэффициент тренда (k): ...
Свободный член (b): ...
Уравнение тренда: y = k * x + b
R²: ...
```

В примере значения заменены многоточиями, поскольку они зависят от выбранного диапазона.

### Что означают k, b и R²?

Линейный тренд рассчитывается по методу наименьших квадратов:

\[
y = kx + b
\]

- **`x`** — начальное число;
- **`y`** — количество шагов до первого попадания в цикл;
- **`k`** — наклон линии тренда;
- **`b`** — свободный член;
- **`R²`** — доля разброса значений, объясняемая этой линейной моделью (для регрессии с константой на обучающих данных обычно от `0` до `1`).

При низком `R²` линейная модель плохо описывает фактическое количество шагов. Даже положительный `k` **не означает**, что у каждого следующего числа шагов больше, чем у предыдущего.

## Правила подсчёта

Для натурального числа `n` применяется правило:

- Если `n` чётное, следующее число равно `n / 2`.
- Если `n` нечётное, следующее число равно `3n + 1`.

Подсчёт останавливается **при первом достижении любого из чисел `1`, `2` или `4`**. Дополнительные переходы внутри цикла не считаются.

Например:

```text
3 → 10 → 5 → 16 → 8 → 4
```

Для `3` результат — **5 шагов**, а для `1`, `2` и `4` — **0 шагов**.

## Ограничения

- Вычисления проверяют только конечный диапазон чисел и **не доказывают гипотезу Коллатца** для всех натуральных чисел.
- Линейный тренд описывает выбранный диапазон, но не является надёжным предсказанием числа шагов для произвольного `n`.
- При большом значении `--count` вычисления и особенно отрисовка графика могут занимать заметное время и память.
